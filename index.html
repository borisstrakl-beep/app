🔥 Firebase nastavitev

Najdeš ga v Firebase Console → Realtime Database → kopiraj URL brez poševnice na koncu
Navodila za nastavitev (3 minute):
  1. Pojdi na console.firebase.google.com
  2. Klikni Add project → vpiši ime (npr. moja-placila) → Continue
  3. Google Analytics → izklopí → Create project
  4. V levem meniju klikni Build → Realtime Database
  5. Klikni Create Database → izberi lokacijo europe-west1
  6. Na vprašanju o pravilih izberi Start in test mode → Enable
  7. Kopiraj URL iz vrha (npr. https://moja-placila-default-rtdb.europe-west1.firebasedatabase.app)
  8. Prilepi URL zgoraj in klikni Shrani in poveži
⚠ Test mode poteče po 30 dneh. Za trajno rešitev v Firebase Console → Realtime Database → Rules nastavi:
{ "rules": { ".read": true, ".write": true } }
